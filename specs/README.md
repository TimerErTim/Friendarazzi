# Specifications & Decisions

`specs/` holds concise product design docs and architecture decision records (ADRs) for **Friendarazzi**.

## Layout

```
specs/
├── README.md          # Overview
├── product/
│   ├── charter.md     # Core Friendarazzi gameplay loop & domain terms
│   ├── visual-identity.md
│   ├── konto.md       # Authentication & account specification
│   ├── betrieb.md     # Operations & health check specification
│   └── datenschutz.md # Privacy & data deletion guarantees
└── decisions/         # Architecture decision records (ADRs)
```
